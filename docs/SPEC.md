# אפיון: ממלכת הפנים, חפיסת כוחות

## הבעיה
קלפי כוחות מאוירים הם כלי חזק לשיחה רגשית, אבל החפיסה הפיזית לא תמיד זמינה, ולא נוחה בשיחה מרחוק. הגרסה הקודמת של האפליקציה הייתה כהה ומופשטת, ולא הרגישה כמו הקלפים.

## המשתמש
- **מנחה**: הורה, מחנך, מטפל או מאמן, עם אדם אחד או עם קבוצה.
- **משתמש עצמאי**: נער או מבוגר שמשתמש לבד.

## הפעולה המרכזית
לשלוף או לבחור קלף, להתבונן באיור, להפוך לשאלה ולתרגול, ולכתוב מה הקלף עורר.

## מסלולים
1. **החפיסה**: 30 קלפים בגריד. לחיצה פותחת קלף בגדול מתחת לסרגל העליון, עם מעבר בין קלפים והיפוך. הכתובת שומרת את הקלף.
2. **שליפה**: שלושה מצבים. קלף אחד (ערבוב תלת־ממדי וחלוקה), בחירה מהמניפה (שבעה קלפים הפוכים), ופריסת שלושה (כוח שכבר יש בי, כוח שאפשר לחזק, כוח לדרך). הכתובת שומרת את הפריסה.
3. **יומן**: רשומות עם תמונות הקלפים, מחיקה, ייצוא לטקסט.
4. **איך משחקים**: שבעה משחקים ליחיד, למשפחה, לכיתה ולחדר הטיפול. שימוש בטוח, פרטיות, התקנה.

## הקלף
- חזית: קלף לבן, חלון צבעי מים, סצנה מונפשת בשלוש שכבות עומק, שם הכוח בתחתית.
- גב: שם, משמעות במשפט אחד, שאלה, תרגול.
- גב החפיסה: צבעי מים כהים עם שמש זהובה וכובע.

## המידע שנשמר
רשומות יומן במכשיר בלבד: סוג השליפה, מזהי הקלפים, הטקסט, תאריך. אין שרת ואין חשבונות.

## קריטריונים להצלחה
- כל כפתור, לשונית וקלף פועלים בנייד ובדסקטופ, בלי גלילה אופקית.
- קישור שמועתק משחזר את אותו קלף או אותה פריסה.
- רשומה נשארת אחרי רענון.
- אין שגיאות התקנה ב-Chrome.
