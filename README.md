# ממלכת הפנים

שתי חפיסות מאוירות ומונפשות בתלת־ממד: **24 שדונים**, הדפוסים והרגשות שמנסים לנהל אותנו (כעס, פחד, דחיינות, קנאה), ו**30 כוחות קסם**, המשאבים הפנימיים שעוזרים מולם. משחקים: משחק זוגות (התאמת כוח לשדון עם נימוק), משחק מלחמה, תעודת זהות לשדון, ושליפות כמו "איזה שדון מנהל אותי עכשיו". מה שנכתב נשמר ביומן במכשיר.

מבנה המשחקים בהשראת "ארץ יצורי הנפש" של הפסיכולוגית אפרת מעיין. לשימוש פרטי. כל השדונים, כוחות הקסם, האיורים והטקסטים מקוריים.

האפליקציה מיועדת לשימוש בליווי מבוגר או מטפל. היא לא מחליפה טיפול ואינה כלי אבחון. פרטים בעמוד ההסבר באפליקציה.

## הרצה מקומית

```bash
npm install
npm run dev
```

בנייה לייצור:

```bash
npm run build
npm run preview
```

יצירה מחדש של האייקונים (PNG, ללא תלויות):

```bash
npm run icons
```

```
  data/cards.js        30 כוחות הקסם, ועזרים לשתי החפיסות
  data/shedim.js       24 השדונים: שם, לחישה, שאלה, כוחות שעוזרים, מראה
  art/Wanderer.jsx     גיבור קלפי הכוחות, עם תנוחות ומפרקים מונפשים
  art/Shed.jsx         השדון: יצור עם אוזניים, עיניים, פה, ידיים ותוספות משתנים
  art/shedScenes.jsx   סצנה ואביזרים לכל שדון
  art/props.jsx        אביזרים: שמש, מים, עץ, אופניים, ינשוף ועוד
  art/scenes.jsx       סצנה לכל קלף בשלוש שכבות עומק
  art/ArtDefs.jsx      מסנני צבעי מים משותפים
  lib/router.js        ניתוב מבוסס hash, כך שהקישור שומר מצב
  lib/store.js         יומן ב-localStorage
  lib/prng.js          צורות אורגניות דטרמיניסטיות
  components/          Card3D, CardArt, CardCover, Particles, TopBar
  pages/               Home, Deck, Draw, Journal, Play
  pages/games/         Pairs (זוגות), War (מלחמה), IdCard (תעודת זהות לשדון)
public/
  sw.js                שירות רשת: מטמון למעטפת ולנכסים
  manifest.webmanifest התקנה כאפליקציה ב-Chrome
  icons/               אייקוני PNG (ללא טקסט)
docs/SPEC.md           אפיון המוצר
CLAUDE.md              החלטות קבועות ואישורים
```

## פרטיות

אין שרת, אין חשבונות ואין שיתוף. הנתונים נשמרים רק ב-localStorage של הדפדפן במכשיר.

## זכויות

לשימוש פרטי. הפורמט נאמן למשחק קלפי כוחות קיים. האיורים, הדמות, המשפטים, השאלות והתרגולים מקוריים, ואינם העתקה של איורי המקור.
