# ממלכת הפנים

אפליקציית ווב לעבודה רגשית עם קלפים תלת־ממדיים ומונפשים. יש שתי חפיסות: **צללים** (דחפים ורגשות מאתגרים) ו**אורות** (כוחות שעוזרים לנהל אותם). המשתמש שולף קלפים, מזווג צל לאור, וכותב מה אפשר לנסות. הרשומות נשמרות ביומן במכשיר.

האפליקציה מיועדת לשימוש בליווי מבוגר או מטפל. היא לא מחליפה טיפול ואינה כלי אבחון. פרטים בעמוד ההסבר באפליקציה.

## הרצה מקומית

```bash
npm install
npm run dev
```

בנייה לייצור:

```bash
npm run build
npm run preview
```

יצירה מחדש של האייקונים (PNG, ללא תלויות):

```bash
npm run icons
```

## מבנה

```
src/
  App.jsx              מעטפת, ניתוב ומעברי עמודים
  main.jsx             נקודת כניסה, רישום שירות רשת
  styles.css           עיצוב כולל תלת־ממד ותנועה
  data/cards.js        תוכן הקלפים (צללים ואורות)
  lib/router.js        ניתוב מבוסס hash, כך שהקישור שומר מצב
  lib/store.js         יומן ב-localStorage
  lib/prng.js          צורות אורגניות דטרמיניסטיות
  components/          Creature (יצור SVG מונפש), Card3D, Particles, TopBar
  pages/               Home, Draw, Pair, Journal, About
public/
  sw.js                שירות רשת: מטמון למעטפת ולנכסים
  manifest.webmanifest התקנה כאפליקציה ב-Chrome
  icons/               אייקוני PNG (ללא טקסט)
docs/SPEC.md           אפיון המוצר
CLAUDE.md              החלטות קבועות ואישורים
```

## פרטיות

אין שרת, אין חשבונות ואין שיתוף. הנתונים נשמרים רק ב-localStorage של הדפדפן במכשיר.

## זכויות

כל השמות, הדמויות והטקסטים באפליקציה מקוריים. הפרויקט אינו מבוסס על ערכת קלפים מסחרית קיימת.
